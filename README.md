# Problemas de Optimización con Programación Dinámica

Soluciones implementadas mediante Programación Dinámica (enfoque Bottom-Up) para dos problemas clásicos de optimización:

1. **Escaleras (`escaleras.py`):** Calcula el número de formas posibles de subir $N$ escalones avanzando 1 o 2 pasos por turno e imprime la tabla DP.
2. **Cambio mínimo de monedas (`cambio_monedas.py`):** Determina el mínimo de monedas requeridas para alcanzar un monto objetivo, reconstruye una combinación válida e imprime la tabla DP.
